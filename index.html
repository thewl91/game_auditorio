Integração Hardware Raspberry Pi 3B

Conecte botões físicos nos pinos GPIO ou use Serial USB

1. Ligação Elétrica dos Botões na Raspberry Pi 3B

  • Botão Jogador 1 (Vermelho): Ligue um fio no GPIO 17 (Pino físico 11) e o outro fio no GND (Pino físico 9).
  • Botão Jogador 2 (Azul): Ligue um fio no GPIO 27 (Pino físico 13) e o outro fio no GND (Pino físico 14).
  • Não precisa de resistor externo! O script abaixo ativa o pull_up=True interno da Raspberry Pi.

2. Script Python para a Raspberry Pi (botoes_auditorio.py)

Este script transforma o aperto nos pinos GPIO 17 e GPIO 27 nas teclas [1] e [2] instantaneamente no navegador Chromium em tela cheia:

#!/usr/bin/env python3
# Instale as bibliotecas na Raspberry Pi 3B:
# sudo apt update && sudo apt install -y python3-gpiozero python3-pynput
from gpiozero import Button
from pynput.keyboard import Controller
from signal import pause
import time

keyboard = Controller()

# GPIO 17 (Pino 11) = Jogador 1 | GPIO 27 (Pino 13) = Jogador 2
btn_jogador_1 = Button(17, pull_up=True, bounce_time=0.05)
btn_jogador_2 = Button(27, pull_up=True, bounce_time=0.05)

def acionar_j1():
    print("JOGADOR 1 APERTOU!")
    keyboard.press('1')
    time.sleep(0.05)
    keyboard.release('1')

def acionar_j2():
    print("JOGADOR 2 APERTOU!")
    keyboard.press('2')
    time.sleep(0.05)
    keyboard.release('2')

btn_jogador_1.when_pressed = acionar_j1
btn_jogador_2.when_pressed = acionar_j2

print("=== BOTOES DO AUDITORIO ATIVOS (GPIO 17 e GPIO 27) ===")
pause()
